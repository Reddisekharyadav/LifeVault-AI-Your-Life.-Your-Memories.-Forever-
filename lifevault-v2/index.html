Privacy & Lock

PIN is stored only as a salted PBKDF2 hash (WebCrypto, 100,000 iterations) — never as plaintext. Older SHA-256-only profiles are upgraded to PBKDF2 on their next successful unlock, and the old hash is then discarded. 5 failed attempts = 30-second lockout. Auto-lock when the tab is hidden.

Backup — file export / import (not clipboard)

Last backup: never

If checked, an in-page dialog asks for the export password (with confirmation and show/hide). The password is cleared after use and is never stored.

Export includes entry text and photo/audio files bundled in the file. On restore, any referenced file that is missing is reported honestly as “N restored, K missing”. Imports are capped at 50 MB and integrity-checked. Older v1 Base64 exports are also accepted where readable.

Reminders (opt-in, off by default, this device only)

Nothing is scheduled server-side. A notification, if allowed, contains only the generic line “A LifeVault reflection prompt is waiting” — never entry text, titles, or capsule content. If notifications are unavailable or denied, the prompt appears in-app on open instead.
